# SleepBeat

**Continuous monitoring of nocturnal arrhythmias using a simulated wrist wearable and machine learning.**

SleepBeat is an academic prototype designed to detect suspicious cardiac rhythm events during sleep. A simulated wearable continuously streams heart rate and RR intervals, which are processed by a machine learning model and converted into risk levels and alerts.

The system is intended as a **screening tool**, not a medical diagnostic system.

## Overview

Nocturnal arrhythmias, particularly paroxysmal atrial fibrillation (AF), may occur without symptoms and can be missed by short monitoring periods such as 24 to 48-hour Holter exams.

SleepBeat explores continuous overnight monitoring using a wearable-style architecture:

```text
Wearable Simulator
       │
       │ MQTT
       ▼
  Mosquitto Broker
       │
       ▼
   FastAPI Backend
       │
       ├──► TimescaleDB / PostgreSQL
       │
       ▼
  Window Processing
     30–60 s
       │
       ▼
 Machine Learning
       │
       ▼
   Risk Engine
       │
       ├──► Dashboard
       ├──► Notifications
       └──► FHIR R4
```

## Main Features

- Simulated wrist wearable generating overnight HR and RR data
- MQTT communication with QoS 1
- 30–60 second analysis windows with 50% overlap
- Heart Rate Variability feature extraction
- Machine learning classification
- Detection of:
  - Normal rhythm
  - Suspected atrial fibrillation
  - Bradycardia / tachycardia
  - Noise
- Three-level risk engine
- Persistent-event detection to reduce false alarms
- Nightly monitoring dashboard
- Simulated notifications and emergency alerts
- FHIR R4 interoperability
- Patient pseudonymization and privacy-oriented design

## Machine Learning

The baseline models are:

- Random Forest
- XGBoost

A **1D CNN** may be evaluated as an extension.

Features extracted from RR intervals include:

- Mean heart rate
- RMSSD
- pNN50
- RR coefficient of variation
- Entropy
- Poincaré SD1 / SD2

The classifier outputs a rhythm class and confidence score. Windows classified as noise are excluded from alert generation.

## Risk Engine

Predictions are aggregated over time rather than generating alarms from isolated classifications.

Conceptually:

```text
Normal / isolated event
        │
        ▼
      Normal

Repeated suspicious events
        │
        ▼
      Warning
        │
        └──► Silent notification

Persistent AF or abnormal HR
        │
        ▼
      Critical
        │
        ├──► Sound alarm
        └──► Emergency contact
```

Thresholds and persistence rules will be calibrated during development.

## Data

Training and evaluation use publicly available **PhysioNet** datasets:

- MIT-BIH Atrial Fibrillation Database
- Long-Term AF Database
- MIT-BIH Arrhythmia Database
- PhysioNet/CinC Challenge 2017

Only RR interval information is used for the core classification pipeline.

Synthetic overnight recordings are also generated by the SleepBeat simulator, with known arrhythmia and noise episodes for end-to-end testing.

## Evaluation

Datasets are split **by patient** to prevent data leakage between training and testing sets.

Planned metrics include:

- Sensitivity
- Specificity
- Per-class F1 score
- AUC
- Event-level detection on simulated nights

## Interoperability

SleepBeat exposes monitoring results using **FHIR R4**, including resources such as:

- `Patient`
- `Device`
- `Observation`
- `RiskAssessment`
- `Flag`

Heart rate observations use **LOINC 8867-4**.

## Privacy

The prototype follows privacy principles inspired by Brazil's **LGPD**, including:

- Pseudonymization
- Data minimization
- TLS-protected MQTT communication
- Authentication
- Encrypted data storage
- Explicit separation between screening and medical diagnosis

The prototype uses only public and synthetic datasets.

## Disclaimer

SleepBeat is an **academic prototype** intended for research and educational purposes.

It is **not a medical device and must not be used for diagnosis or clinical decision-making**. Any suspected arrhythmia detected by the system would require confirmation by a qualified healthcare professional using appropriate clinical methods such as ECG.
